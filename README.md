# Aozora-proof

Proofread Aozora Bunko text with a Rust CLI and library.

## Installation

```sh
git clone https://github.com/P4suta/aozora-proof.git
cd aozora-proof
cargo install --locked --path crates/aozora-proof-cli --bin aozora-proof
```

## Usage

```sh
aozora-proof check --orthography mixed manuscript.txt
```
